# Accessible Restaurant Review App

An accessible web application for reviewing restaurants with a focus on accessibility features.

## Features

- View restaurant listings with accessibility information
- Submit reviews with star ratings
- Upload images with reviews
- Fully accessible interface (WCAG compliant)
- Responsive design for all devices

## Setup

1. Create a Firebase project and enable Firestore and Storage
2. Add your Firebase config to `js/firebase.js`
3. Add restaurant images to the `images/` folder
4. Open `index.html` in a browser

## Deployment

1. Push to GitHub
2. Enable GitHub Pages in repository settings

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase (Firestore, Storage)
- Bootstrap 5

## Accessibility Features

- Semantic HTML structure
- ARIA attributes for screen readers
- Keyboard navigation
- High contrast mode support
- Focus management
- Text alternatives for images
