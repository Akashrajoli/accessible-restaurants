# Accessible Restaurants App

An accessible web application for discovering and reviewing accessible restaurants.

## Features

- Accessible design following WCAG guidelines
- Screen reader compatible
- Keyboard navigable
- High contrast mode support
- Voice recording for reviews
- Text-to-speech for reviews

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Web Speech API

## Setup

1. Clone this repository
2. Open `index.html` in your browser
